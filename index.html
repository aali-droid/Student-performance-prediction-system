🧠 What is Machine Learning?

Machine Learning (ML) enables computers to learn patterns from historical data and make predictions without being explicitly programmed for every scenario. Here, the model learns how study time, failures, absences, G1, and G2 relate to the final grade (G3).

📐 What is Linear Regression?

Linear Regression fits a linear equation ŷ = β₀ + β₁x₁ + … + βₙxₙ by minimizing the sum of squared residuals between actual and predicted grades.

🔀 Why an 80:20 Train-Test Split?

80% of the data trains the model and 20% (held out with random_state=42) evaluates how well it generalizes to unseen students, preventing data leakage.

📊 Evaluation Metrics (MAE & R²)

MAE (1.3394): Predictions deviate from the actual grade by ~1.34 marks on average.
R² Score (0.7822): The model explains ~78.2% of the variance in final grades.

ℹ️ About This Project
Student Performance Prediction using Machine Learning

🎓 Project Title

Student Performance Prediction System using Linear Regression

📄 Abstract

This project develops an interactive web application that predicts students' final examination grades in Mathematics using Linear Regression trained on the UCI Student Performance dataset (student-mat.csv).

🔍 Problem Statement

Educational institutions need early-warning mechanisms to identify students who may need extra support. Historical academic data and Linear Regression provide timely, data-driven performance estimates.

🛠️ Technologies Used

Python Streamlit Pandas NumPy Scikit-learn Plotly HTML / CSS / JS

📦 Dataset Source

UCI Machine Learning Repository — Student Performance Dataset (student-mat.csv).
